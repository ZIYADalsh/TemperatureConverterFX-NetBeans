# Algorithms

## Problem Definition
تحويل درجات الحرارة بين سلسيوس وفهرنهايت.

## Formulas
- F = C × 9/5 + 32
- C = (F − 32) × 5/9

## خطوات العمل (خوارزمية مبسطة)
1. اقرأ إدخال المستخدم كعدد عشري.
2. حدد اتجاه التحويل من القائمة.
3. طبّق المعادلة المناسبة.
4. اعرض النتيجة منسّقة برقمين عشريين.
5. عالج الأخطاء عند إدخال نص غير رقمي.
