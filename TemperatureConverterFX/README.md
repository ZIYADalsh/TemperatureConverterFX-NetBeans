# TemperatureConverterFX

JavaFX app for converting between Celsius and Fahrenheit. Built as a Maven project for NetBeans.

## Run (NetBeans)
1. افتح **File → Open Project…** واختر مجلد `TemperatureConverterFX`.
2. تأكد أن الـ JDK هو 17 أو أحدث.
3. من قائمة المشروع اختر **Run**.

## Run (CLI)
```
mvn clean javafx:run
```

## المتطلبات المغطاة
- استخدام JavaFX لواجهة رسومية.
- الكود مع تعليقات وشرح الخوارزمية.
- توثيق كامل داخل مجلد `Documentation`.
- تقرير نهائي وقائمة فحص.
