# TemperatureConverterFX

A JavaFX desktop application for converting temperature values between Celsius, Fahrenheit, and Kelvin.

## Overview
This project is a simple graphical user interface built with JavaFX and Maven. It allows users to enter a temperature value and instantly convert it between units using a clean and modern interface.

## Features
- Conversion between Celsius, Fahrenheit, and Kelvin
- Real-time calculation as the user types
- Clean JavaFX desktop UI
- Unit-tested conversion logic
- Maven-based project setup

## Technologies Used
- Java 17
- JavaFX 21
- Maven
- JUnit 5

## Project Structure
- `TemperatureConverterFX/` – main JavaFX project folder
- `src/main/java/` – Java source code
- `src/main/resources/` – FXML, CSS, and image assets
- `src/test/java/` – unit tests
- `Documentation/` – project reports and documents

## Run the Project
1. Open the project in NetBeans or any Java IDE.
2. Make sure Java 17+ is installed.
3. Run Maven dependencies:
   ```bash
   mvn clean install
   ```
4. Launch the app:
   ```bash
   mvn javafx:run
   ```

## Test the Application
```bash
mvn test
```
